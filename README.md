**Cart App**

A sample Android shopping cart application built using Jetpack Compose and MVVM architecture. 
The app demonstrates modern Android development practices including StateFlow, State Hoisting,
Repository Pattern, Unidirectional Data Flow (UDF), and reactive UI updates.

**Features**

-Dynamic product listing

-Add/Remove product quantity

-Manual quantity input

-Real-time cart item count

-StateFlow-based state management

-MVVM architecture

-Repository pattern

-Stateless composables with State Hoisting

**Tech Stack**

Kotlin

Jetpack Compose

ViewModel

StateFlow

Coroutines

MVVM Architecture

**Learning Outcomes**

Managing UI state with StateFlow

Implementing State Hoisting in Compose

Building reusable and stateless composables

Handling one-time UI events using SharedFlow

Separating concerns using MVVM and Repository Pattern

Creating scalable and maintainable Android applications
